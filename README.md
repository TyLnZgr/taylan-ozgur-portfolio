# Taylan Özgür Taşkırdı — Portfolio

A personal portfolio for frontend engineer Taylan Özgür Taşkırdı. It features verified professional experience, selected public GitHub projects, a categorized toolkit, and direct contact links.

**Live portfolio:** [tylnzgr.github.io/taylan-ozgur-portfolio](https://tylnzgr.github.io/taylan-ozgur-portfolio/)

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

The site is a static Vinext export. Portfolio content lives in `data/portfolio.ts`; the main interface is in `components/Portfolio.tsx`. Project imagery is sourced from the owner's public repositories. Pushes to `main` publish the GitHub Pages build automatically.
